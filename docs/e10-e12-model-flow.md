# E10 与 E12 模型流程图

本文档描述当前代码中 E10、E12 的实际执行流程。流程图使用纯文本绘制，不依赖 Mermaid。

## E10：D-FINE-L RGB-T 输入残差融合

```text
训练样本
  │
  ├── RGB 图像 ────────────────┐
  │                            │
  └── IR 图像                  │
       │                       │
       ├── 2×均值池化与上采样 ─┤
       │        得到低频 IR     │
       │                       │
       └── IR - 低频 IR        │
                得到高频 IR     │
                │              │
                ▼              │
        [低频 IR, |高频 IR|]    │
                │              │
                ▼              │
       Conv-BN-SiLU-Conv        │
                │              │
                ▼              ▼
              IR 残差 ───────► RGB + gate × IR 残差
                                      │
                                      ▼
                            三通道融合输入（伪 RGB）
                                      │
                                      ▼
                              HGNetv2-B4 主干
                                      │
                     ┌────────────────┼────────────────┐
                     ▼                ▼                ▼
                 P3 / stride 8    P4 / stride 16   P5 / stride 32
                     └────────────────┼────────────────┘
                                      ▼
                         HybridEncoder（FPN + PAN）
                                      │
                                      ▼
                         三尺度 256 通道检测特征
                                      │
                                      ▼
                    D-FINE Transformer（300 queries）
                                      │
                   ┌──────────────────┴──────────────────┐
                   ▼                                     ▼
             类别置信度                              精细边框回归
                   └──────────────────┬──────────────────┘
                                      ▼
                         Top 100 检测框与 12 类结果
```

E10 的融合只发生在骨干网络输入端。RGB 是主路径，IR 被拆分为低频与高频后生成一个三通道残差，再加到 RGB 上。适配器最后一层采用零初始化，因此开始微调时等价于原始 RGB 预训练输入，随后才逐渐学习 IR 增益。

关键配置：

- 输入：RGB + IR，共 6 通道；训练和验证统一缩放到 `960 × 960`。
- 骨干：HGNetv2-B4，输出 P3、P4、P5 三个尺度。
- 检测器：D-FINE-L，300 个查询，提交时保留前 100 个预测。
- 当前排行榜成绩：`54.825`。

## E12：D-FINE-L RGB-T 小波门控四尺度融合

```text
同步增强后的 RGB + IR（864 × 1536）
  │
  ├──────────────────── RGB 主路径 ──────────────────────────────┐
  │                                                               │
  └── IR 辅助路径                                                  │
       │                                                           │
       ├── 10% 模态随机失活                                        │
       │        │                                                  │
       │        ├── E10 低/高频输入适配器 ──► 加到 RGB ────────────┤
       │        │                                                  │
       │        └── 轻量 IR 特征金字塔                             │
       │             ├── A2 / stride 4                             │
       │             ├── A3 / stride 8                             │
       │             ├── A4 / stride 16                            │
       │             └── A5 / stride 32                            │
       │                                                           ▼
       │                                                   HGNetv2-B4 主干
       │                                                           │
       │               ┌───────────────────────────────────────────┤
       │               │                    │                      │
       ▼               ▼                    ▼                      ▼
      A2          RGB P2 特征           RGB P3 特征            RGB P4/P5 特征
       │               │                    │                      │
       └──────► 小波门控残差融合      ◄──── A3/A4/A5 分别注入 ─────┘
                       │
          ┌────────────┴─────────────────────────────────────┐
          │ 单个尺度内的 WaveletGatedResidualFusion          │
          │                                                   │
          │ RGB 特征 ─► 1×1 降维 ─► Haar DWT ─► LL/LH/HL/HH │
          │ IR  特征 ─► 1×1 降维 ─► Haar DWT ─► LL/LH/HL/HH │
          │                                                   │
          │ LL：拼接后卷积，学习低频结构残差                  │
          │ 高频：按绝对响应选择细节，由可学习通道尺度控制     │
          │ 门控：根据 RGB/IR 低频质量生成空间质量权重         │
          │                                                   │
          │ 低频残差 + 高频残差 ─► Haar IDWT ─► 1×1 恢复通道 │
          │                                      │            │
          │ RGB 原特征 + 空间门控 × 融合残差 ◄───┘            │
          └────────────┬─────────────────────────────────────┘
                       │
          ┌────────────┼────────────┬────────────┐
          ▼            ▼            ▼            ▼
     F2 / stride 4  F3 / stride 8 F4 / stride 16 F5 / stride 32
          └────────────┼────────────┴────────────┘
                       ▼
            HybridEncoder（四尺度 FPN + PAN）
                       │
                       ▼
           四尺度 256 通道检测特征
                       │
                       ▼
        D-FINE Transformer（4 levels、300 queries）
                       │
                       ▼
          分类 + 精细分布边框回归 + Top 100
```

E12 同时保留 E10 的输入残差路径，并在 HGNetv2 的四个阶段加入 IR 特征级小波残差。新增低频输出层和高频尺度都从零开始，因此初始化时 P3/P4/P5 与 E10 完全一致；模型可以学习使用 IR，也可以在 IR 质量差时退化回 RGB 主路径。

## E10 权重迁移到 E12

```text
E10 最优 checkpoint
       │
       ├── 原样加载：输入适配器、HGNetv2-B4、D-FINE decoder
       │
       ├── 位置迁移：E10 encoder 的 P3/P4/P5 参数
       │                  │
       │                  └── 移到 E12 encoder 的 level 1/2/3
       │
       └── 新建参数：P2 encoder 投影、IR 金字塔、四个小波融合模块
                          │
                          └── 融合残差零初始化
```

这避免了因为插入 P2 而把旧 P3 权重错误加载到新 P2 上。D-FINE 交叉注意力的每层采样点总数仍为 12，因此原 decoder 权重可以继续复用。

## E12 训练到提交

```text
E10 最优权重
    │
    ▼
类别均衡训练集（repeat-power 0.35，最多重复 4 次）
    │
    ▼
E12：batch 3 × 梯度累积 5 = 有效 batch 15
    │
    ▼
FP32 AdamW + 分组学习率 + EMA + 两阶段最优权重保存
    │
    ▼
优先选择 best_stg2.pth，其次 best_stg1.pth，最后 last.pth
    │
    ▼
1000 个测试样本推理
    │
    ▼
runs/e12_dfine_l_rgbt_wavelet_p2/submission.zip
```

## 核心差异

| 项目 | E10 | E12 |
|---|---|---|
| 模态 | RGB + IR | RGB + IR |
| 主模态 | RGB | RGB |
| 融合位置 | 仅输入端 | 输入端 + 主干四尺度 |
| 融合方式 | 低/高频输入残差 | Haar 小波低频融合、高频选择、空间质量门控 |
| 检测尺度 | P3/P4/P5 | P2/P3/P4/P5 |
| 输入分辨率 | 960 × 960 | 864 × 1536 |
| 小目标策略 | stride 8 起始 | 增加 stride 4 的 P2 |
| IR 失活 | 无 | 训练时 10% |
| 单卡 batch | 4 | 3 |
| 梯度累积 | 1 | 5 |
| 有效 batch | 4 | 15 |
| 初始化 | 官方预训练后微调 | 从 E10 最优权重迁移，新融合残差为零 |

E12 仍然是双模态模型，没有加入 Depth。Depth 应在 E12 的 RGB-T 改进得到榜分验证之后，以可退化的辅助分支单独做下一阶段实验。
